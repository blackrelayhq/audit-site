Sample audit: a BNB Chain token project

Anonymized: the project name, domain and logo are withheld and blurred. Checked 15 Oct 2026 using only what any visitor can see (public pages and response headers). This was not client work, and the project has not reviewed it. Lighthouse figures are lab tests, not real-user data.

Findings

1. The hero has no headlineUX / conversion

The page source has no headline in the hero, only a contract-address line and a block-explorer link. On desktop, the big first view shows almost nothing that explains the project (screenshot items 1–2).

Fix: Add a one-line value proposition (H1) and a primary call to action above the contract address.

2. All five footer social links go nowhereTrust signals

The Facebook, Twitter, Instagram, LinkedIn and YouTube icons all link to "#". People checking whether a token is legitimate click these first, and dead links look unfinished.

Fix: Link the real accounts, or remove icons for channels you don't run.

3. No security headers at allWeb hygiene

The homepage response has no Strict-Transport-Security, Content-Security-Policy, X-Frame-Options, X-Content-Type-Options or Referrer-Policy header. That means the page can be embedded in another site, which matters here because it has buttons people act on.

Fix: Add these headers in the web server config, starting with HSTS, X-Frame-Options: DENY (or a frame-ancestors CSP) and nosniff.

4. The server software is advertised in headersWeb hygiene

The response headers announce the web server version and the framework (X-Powered-By).

Fix: Remove the X-Powered-By headers and the server version banner.

5. Main content takes 8.3 s to appear on mobileSpeed (lab)

A Lighthouse mobile lab run measured LCP at 8.3 s and first paint at 3.9 s. About 171 KB of JavaScript goes unused on load, mostly a chat widget and a slider library.

Fix: Load the chat widget after the user interacts or the page is idle, and compress and preload the hero image.

6. Icon-only buttons have no labelsAccessibility

The copy-address and scroll-to-top buttons have no accessible name, and the stat numbers fail the colour-contrast check (Lighthouse).

Fix: Add aria-labels and raise the contrast of the stat numbers.
