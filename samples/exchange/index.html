Sample audit: a centralized crypto exchange

Anonymized: the project name, domain and logo are withheld and blurred. Checked 15 Oct 2026 using only what any visitor can see (public pages and response headers). This was not client work, and the project has not reviewed it. Lighthouse figures are lab tests, not real-user data.

Annotated screenshot of the key issues

Findings

1. The homepage takes about a minute to finish loading on mobileSpeed (lab)

In a Lighthouse mobile lab run, the first content appeared at 21.8 s and the main content at 59.2 s. The page downloads about 10.5 MB, including a 2.1 MB main app script, and roughly 2.4 MB of JavaScript goes unused.

Fix: Split the JavaScript bundle per route, defer third-party scripts, and server-render the hero.

2. No security headers on the homepageWeb hygiene

The response has no Strict-Transport-Security, Content-Security-Policy, X-Frame-Options or X-Content-Type-Options header. The page has login and sign-up actions, so missing frame protection matters here.

Fix: Add HSTS, X-Frame-Options: DENY (or CSP frame-ancestors 'none') and nosniff at the CDN or load balancer.

3. The headline is a promo slogan, not a value propositionUX / conversion

The hero headline advertises daily campaigns. It doesn't tell a new visitor that this is an exchange, or why to choose it (screenshot item 1).

Fix: Lead with what the exchange is and its main advantage, and keep the campaign as a secondary banner.

4. Typo on a key trust statTrust signals

The user-count stat has a grammar error (screenshot item 3). Small errors on headline numbers make visitors doubt the numbers.

Fix: Correct the wording.

5. Console errors and failed requests on loadQuality

Lighthouse logged failed resource loads (404) and a third-party script error on the homepage.

Fix: Fix or remove the broken resource URLs and the failing library.

6. Unlabelled buttons, links and imagesAccessibility

Lighthouse flags icon-only buttons with no name, social links with no readable text, images without alt text, and low-contrast text.

Fix: Add aria-labels and alt text, and raise the contrast of small text.

7. No robots.txtSEO

/robots.txt returns 404. A sitemap.xml exists, but crawlers aren't pointed to it.

Fix: Publish a robots.txt containing a Sitemap: line.
